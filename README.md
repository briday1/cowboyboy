# Cowboyboy · The Night Final

A first-person horror game set during a timed horse anatomy exam. Look down to write on the exam sheet, then look up to respond to directional cues around the room.

[Play on GitHub Pages](https://briday1.github.io/cowboyboy/)

Use the arrow keys or the on-screen controls to look around. Click the paper or press 1–4 to answer. Use E or the interaction button to respond to threats and collect Bean Bonus tins. Press Esc to pause.

To run locally, serve this directory with `python3 -m http.server 8000` and open `http://localhost:8000/`. GitHub Pages deploys the root game on pushes to `main`. The original minigame build is archived on [classic-minigames](https://github.com/briday1/cowboyboy/tree/classic-minigames).
